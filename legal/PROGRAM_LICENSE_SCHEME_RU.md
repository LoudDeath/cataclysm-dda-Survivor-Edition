## Область действия и переход

Исходная программная основа CDDA 0.I (commit
27939e29b8b4ddc081490d9f51de59a459c88df6) получена по CC BY-SA 3.0.
Это уведомление не меняет лицензию upstream, чужие авторские права или права
на отдельные неизменённые ресурсы.

Для программной адаптации издания применяется следующая последовательность:

1. Адаптация CC BY-SA 3.0 распространяется по более поздней CC BY-SA 4.0
   в пределах разрешения §4(b) исходной лицензии. Изменения программной основы
   перечислены в EDITION_CHANGES.md и PROGRAM_ADAPTATION.patch; исходные
   уведомления и атрибуция сохраняются. Компоненты с отдельными лицензиями
   этим шагом не перелицензируются.
2. Изменённая программная основа включается в объединённую программу с
   simplexnoise Eliot Eshelman. Для вклада в эту объединённую адаптацию
   выбирается GNU GPL **version 3 only**, по односторонней совместимости
   CC BY-SA 4.0 с GPLv3. Не заявляется совместимость с будущими версиями GPL.
   Исходные разрешения CC сохраняются; это не исключительное перелицензирование
   чужих файлов. Нельзя извлечь simplexnoise и объявить его CC BY-SA.

Применимость этой двухступенчатой схемы именно к программной адаптации CDDA —
вывод для данного кандидата из приведённых первичных условий, а не готовое
индивидуальное заключение правообладателей. Проверить её перед коммерческой
передачей остаётся пунктом LIC-REVIEW-001. Сам компонент simplexnoise не менялся;
поведение генерации мира и погоды сохранено.

Ultica, JSON, переводы, звуки, шрифты и магазинное оформление учитываются
отдельно по реестру. Их соседство в архиве не делает все файлы GPL.
Собственные изменения переводов сохраняют ShareAlike исходной базы.
Freetype выбирается по FTL, Zstandard по BSD; LGPL mpg123 допускает работу
в GPLv3-программе с сохранением исходных уведомлений и прав библиотеки.

## Соответствующие исходники получателю

В каждом игровом архиве предусмотрен legal/source/corresponding-source.zip:
исходники программы, заголовки, проекты MSVC, ресурсы сборки, scripts,
закреплённые версии, полный редактируемый PO перевода, исходные архивы всех
16 runtime-пакетов vcpkg, 20 точных портов с патчами и рецепты vcpkg.
Архив не зависит от наличия .git. SHA-512 каждого внешнего архива совпадает
с установленным SPDX; проверка записана в assets/third-party-source/dependencies/MANIFEST.json.
Дополнительно передаются исходники Unifont12.0.01 и legal/source/relink-kit.zip
с материалами замены статической LGPL-библиотеки.

Таким образом подготовлен способ передачи бинарника вместе с исходниками
при сетевой загрузке (§6 GPLv3). Одна ссылка на чужой GitHub или обещание
предоставить исходники в будущем не используются как замена этому комплекту.
Сборка из именно упакованного снимка на чистой машине ещё UNKNOWN;
проверка наличия и контрольных сумм не подменяет такую сборку.

MSVC/Windows SDK, Python и CMake — общие инструменты сборки. Исходники
системных библиотек не включаются по исключению System Libraries §1 GPLv3.
Для данной конфигурации это касается штатных Windows API и CRT поставки
компилятора. Это основание нужно повторно проверить при добавлении DLL,
стороннего SDK или нестандартной библиотеки; исходники игровых библиотек
этим исключением не подменяются. Посторонние proprietary SDK сейчас не добавлены.

## Права покупателя и условия магазина

Продажа разрешённых копий совместима с GPL; покупатель получает также права
копировать, изменять и распространять программу на условиях лицензии.
Нет общего запрета на reverse engineering для разрешённых модификаций.
Поставка без гарантии в пределах, допускаемых обязательным законом;
полный текст GPLv3 и исходные отказы от гарантий приложены.

Издатель должен сверить фактические условия кабинета VK Play, EULA и механизм
доставки: они не должны вводить дополнительные ограничения этих прав.
Тестовое шифрование из документа 1393 не доказывает совместимость финальной
доставки с лицензиями. Обязательны доступность исходников получателю и
возможность запуска его изменённой сборки. Ключи разработчика не требуются
для прямого запуска локальной изменённой Windows-сборки; их нельзя включать
в исходники. Проверка установки через Game Center ещё UNKNOWN.

## Открытые проверки

- LIC-REVIEW-001: подтвердить применимость описанного перехода к CDDA;
  ответственный — издатель, при необходимости специалист по открытым лицензиям.
- LIC-SOURCE-002: выполнить чистую сборку из переданного снимка с bundled source
  cache и отдельно проверить замену изменённой mpg123. Сейчас UNKNOWN.
- LIC-PLATFORM-003: проверить реальный договор VK Play, дополнительные условия
  и доставку исходников вместе с бинарником. Сейчас UNKNOWN.
- Права на отдельные ресурсы/упоминания, реквизиты и возрастная маркировка:
  LICENSE_AUDIT_RU.md и CONTENT_REVIEW_PENDING_RU.md. Эта схема их не разрешает.
