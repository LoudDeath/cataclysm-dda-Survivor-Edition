## Как читать полный журнал

`old_en/new_en` — точное исходное и новое поле. `old_ru/new_ru` — действовавший перевод; для множественного числа сохранены все четыре формы каталога.
`file` и `field_or_context` указывают файл и JSON Pointer либо контекст C++. Для рецептов в журнале записаны фактические изменения компонентов и количеств.
Пустое исходное значение означает добавление нового поля или ресурса. Пустой перевод у технического поля означает, что поле не выводится как текст.

- Сохранность существующих ID: PASS.

- Реальные названия в действующих RU/EN строках: 0 находок.
- Точный отчёт: audits/content/CONTENT_CHECKS.json. Игровые проверки и ограничения записаны отдельно.
